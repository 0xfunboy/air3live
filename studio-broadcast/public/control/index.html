VOICE NARRATION & PHONETIC LIP-SYNC

AI Speech Synthesis Synchronized to 3D Visemes in Real-Time.

Compatible with any OpenAI audio/speech API endpoint (Pocket-TTS, Kokoro, ElevenLabs, OpenAI). Audio is phonetically mapped to AIR3 3D viseme mouth shapes via the embedded Rhubarb LipSync engine.

Narrations dispatched by ElizaOS or the operator are processed sequentially via FIFO queue with viseme lip-sync alignment.

REST Endpoint: POST /api/live/narrations · {"text": "...", "language": "en"}
