## Changes in the derived runtime clips

The runtime clips in `studio-broadcast/public/assets/air3/motion/accad-female1.mjs` are derivatives: selected frame ranges, world-space retargeting to the existing AIR3 body bind axes, original target bone lengths, travel direction normalized while preserving pelvic yaw in straight locomotion; recorded turn yaw separated for stage steering, recorded root distance retained for navigation, correction of optical capture floor drift, a smooth distributed loop-closure correction and interpolation between samples. The seven clips retain this CC BY 3.0 attribution. The runtime controller uses capture contact labels to stabilize stance feet; the gait is not generated by sine waves or alternating procedural step trajectories.

Retargeting and runtime integration changes by the AIR3 / airewardrop project. Preserve this credit, the source link, the license link and the modification notice when redistributing these motion assets.
