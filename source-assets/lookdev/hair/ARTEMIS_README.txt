Hair: Artemis
A ponytail with long side bangs, available in six different colors. 
Remixed from "Arika the 1st Path" by @antoinepavia. (Thank you!) The user has since deleted their account, but it was licensed CC-BY. Mesh/hair alpha from original, hair texture new. It is rigged (simple, but functional). 

Note: This entire set is free because the character was never completed. However I got a bit further with this part and it shouldn't need much modification.

Specs -  

Fresh, crisp quads, mid-poly resolution. Clothing textures: 4096 diffuse, 2048 normal, 1024 specular. Accessory/hair textures: 2048 diffuse, 2048 normal, 1024 specular. It's debatable whether or not this style qualifies as PBR. It’s high-res, but not hyperrealistic. Partly hand-painted, partly photo-ref materials. Use it in any way that works for you.

FBX format, rigged, includes the rest of the armature. My bone names are standardized, but each character has their own custom skeleton (don’t we all?)
