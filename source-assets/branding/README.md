# Branding Assets Intake: `airewardrop`

Questa cartella è destinata ad accogliere i file grafici e vettoriali ufficiali del brand **airewardrop** forniti dal committente per sostituire la precedente dicitura `#AIR3`:
- Logo principale orizzontale (PNG trasparente ad alta risoluzione o SVG vettoriale)
- Pittogramma / Icona del brand (quadrata / circolare)
- Linee guida colore primario/secondario per l'illuminazione dello studio e i banner dei monitor

## Aggiornamento 2.3

`banner-2026-10-25/` conserva il banner selezionato dall’utente e le estrazioni PNG trasparenti ottenute con imagegen. Il runtime della 2.3 usa i nuovi lockup e contorni SVG descritti in `docs/BRANDING_2.3.md`: un marchio aziendale nel set, uno nella grafica esterna e #AIR3 sulla scrivania. La figura del banner non è usata nei loghi. Le versioni SVG e PNG runtime sono in `studio-broadcast/public/assets/air3/branding/`. La ricostruzione tipografica della scritta aziendale usa contorni DejaVu Sans Bold; la relativa licenza è conservata nella stessa cartella sorgente.
