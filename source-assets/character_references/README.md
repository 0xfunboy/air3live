# Riferimenti Morfologici e Visivi Avatar

Questa cartella è destinata ad accogliere le fotografie e i riferimenti visivi forniti dal committente per l'allineamento estetico dell'avatar:
- **Occhi**: Tonalità blu più profonda e vibrante rispetto all'attuale nocciola/hazel; distanza interpupillare leggermente incrementata.
- **Acconciatura**: Coda di cavallo corta posteriore, ciuffi liberi morbidi che scendono verso le spalle, attaccatura sfumata (feathered/gradient hairline), rimozione totale dello chignon/"cipolla".
- **Fisionomia**: Proporzioni armoniose da conduttrice televisiva reale secondo la foto di riferimento.
